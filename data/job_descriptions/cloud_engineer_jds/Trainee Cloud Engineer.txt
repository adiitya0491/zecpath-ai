Trainee Cloud Engineer
Role Overview
A Trainee Cloud Engineer undergoes formal training to develop core cloud engineering skills
before transitioning into a full-time cloud role.
Key Responsibilities

• Participate in cloud training programs
• Perform guided cloud setup and maintenance tasks
• Learn infrastructure automation and security basics
• Support cloud monitoring and support activities
• Complete assigned assessments and projects
Required Skills
• Basic IT and networking knowledge
• Interest in cloud computing and automation
• Strong learning attitude
Experience & Qualifications
• Fresher or career switcher
• Degree or diploma in IT, CS, or related field
