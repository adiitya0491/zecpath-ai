\# Zecpath AI System Repository



\## Overview

This repository contains the modular AI services for \*\*Zecpath\*\*, an AI-powered autonomous hiring platform.



The AI system supports:

\- Resume parsing \& ATS scoring

\- Candidate screening automation

\- Interview intelligence modules

\- Behavioral monitoring

\- Final hiring decision recommendation



---



\## Folder Structure



| Folder | Purpose |

|--------|---------|

| data/ | Sample resumes and job descriptions |

| parsers/ | Resume parsing modules |

| ats\_engine/ | ATS scoring and ranking logic |

| screening\_ai/ | Screening assistant modules |

| interview\_ai/ | Interview intelligence engine |

| scoring/ | Final scoring and decision engine |

| utils/ | Logging and helper utilities |

| tests/ | Unit testing suite |

| logs/ | Log storage |
