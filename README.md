# Zecpath AI - End-to-End Intelligent Hiring Platform

## Project Overview

Zecpath AI is a complete end-to-end AI-powered hiring platform developed during a 70-day internship project.

The system automates the entire recruitment lifecycle, from resume analysis to final hiring decisions, while providing scalable, explainable, and production-ready AI services.

# Setup Instructions

## 1. Clone Repository

```bash
git clone <your-repository-url>

cd zecpath-ai
```

## 2. Create Virtual Environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 4. Run the Project

```bash
python main.py
```
