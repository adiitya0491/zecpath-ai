# Zecpath Technical Interview AI – System Blueprint

## Objective

To conduct adaptive, role-based technical interviews with dynamic difficulty progression and technical evaluation.

---

## Core Components

### 1. Role & Skill Mapper

Maps job roles to technical skills.

Examples:

- MERN Developer → JavaScript, React, Node.js, MongoDB
- Java Developer → Java, Spring Boot, Microservices
- DevOps Engineer → Docker, Kubernetes, CI/CD, AWS
- Data Scientist → Python, Machine Learning, Statistics

---

### 2. Question Engine

Generates questions based on:

- Job Role
- Experience Level
- Difficulty Level

---

### 3. Difficulty Engine

Adjusts question difficulty dynamically.

Rules:

- Strong Answer → Increase Difficulty
- Weak Answer → Reduce Difficulty
- Average Answer → Keep Same Difficulty

---

### 4. Answer Evaluation Engine

Evaluates:

- Correctness
- Concept Understanding
- Problem Solving Ability
- Explanation Quality

---

### 5. Follow-Up Engine

Generates deeper technical questions.

Example:

Question:
What is React?

Strong Answer:
Explain React Hooks.

---

### 6. Technical Scoring Engine

Evaluates:

- Technical Accuracy
- Depth of Knowledge
- Optimization Thinking
- Communication Quality

---

### 7. Report Generator

Generates:

- Technical Score
- Strengths
- Weaknesses
- Hiring Recommendation

---

## System Flow

Start
↓
Role Mapping
↓
Experience Detection
↓
Question Generation
↓
Answer Evaluation
↓
Difficulty Adjustment
↓
Technical Scoring
↓
Report Generation
↓
End
