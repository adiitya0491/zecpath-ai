# Hiring Intelligence Report Generator – Zecpath AI

## Objective

Generate a recruiter-ready hiring report by combining all candidate evaluation stages into one structured profile.

---

## Evaluation Sources

1. ATS Analysis
2. Screening Interview
3. HR Interview
4. Technical Interview
5. Machine Test
6. Behavioral Analysis
7. Integrity Detection
8. Final Recommendation AI

---

ATS

↓

↓

↓
