# Zecpath AI Compliance Design

## Objective

Ensure the HR Interview AI system complies with ethical, privacy,
and data-protection requirements.

---

# Consent-Based Data Usage

Candidates must provide consent before:

- AI interview begins
- Audio recording
- Video recording
- Data storage
- Data processing

Consent must be:

- Explicit
- Logged
- Timestamped

---

# Data Retention Policy

| Data Type | Retention |
|------------|------------|
| Resume | 90 Days |
| Transcript | 60 Days |
| Reports | 120 Days |
| Audit Logs | 180 Days |

After expiration:

- Delete
OR
- Anonymize

---

# Compliance Principles

- Consent First
- Data Minimization
- Secure Storage
- Auditability
- Transparency

---

# Compliance Checklist

- Consent captured
- Data encrypted
- Audit logs enabled
- Retention policy enforced
- Access control enabled
