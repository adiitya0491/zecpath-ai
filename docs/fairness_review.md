# AI Fairness Evaluation Report

## Objective

To identify and minimize bias within the Zecpath AI Hiring System.

---

# Bias Analysis

| Risk Area      | Action Taken                             |
| -------------- | ---------------------------------------- |
| Name Bias      | Removed from scoring                     |
| Gender Bias    | Not used in model                        |
| Religion Bias  | Not used in model                        |
| Caste Bias     | Not used in model                        |
| Accent Bias    | Reduced through transcript normalization |
| Location Bias  | Removed from scoring                     |
| Education Bias | Weight reduced                           |
